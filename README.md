# PlotVista — Transparent Residential Plots & 3D Virtual Tours

PlotVista is an architectural discovery and verification platform for planned residential land across Northern India (Kanpur, Lucknow, Noida, and emerging corridors). It enables prospective land buyers to explore residential layouts, master plans, and true-to-scale street-level 3D perspectives before visiting physically.

## Key Features

- **Multi-Angle 3D Street View**: Interactive Google Street View-like ground walkthroughs (12M Front Boulevard, Driveway & Porch, East Side Garden, Rear Lane, and Corner Avenues).
- **Interactive Architectural Master Plans**: Interactive SVG blueprints with plot dimensions, setbacks, facing direction, and status filtering.
- **RERA & Registry Verification**: Certified plot boundaries, sanctioned layouts, and underground utility conduits.
- **Daylight & Solar Studies**: Real-time lighting simulations across morning, noon, and golden hour.

## Local Development

```sh
bun install
bun run dev
```

Server will run on `http://localhost:8081/`.
